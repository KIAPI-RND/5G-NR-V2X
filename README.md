[5G-NR-V2X] 
 1. 프로젝트 저장소 목적
  - 본 Github 공유 저장소는 5G-NR-V2X 연구과제의 V2X 통신 단말기의 API를 연계하여 V2X 메시지 송신 / 수신,
    차량시스템과 정보 연계를 위한 인터페이스 기술 개발을 위한 목적의 SW를 관리하기 위한 저장소
  - 자체 / 외산 IP의 V2X 장치인 OBU 또는 RSU의 정보를 연계할 수 있도록 관련 프로토콜 메시지와 샘플 코드 구성
  - V2X 장치와 차량시스템(또는 Back-End 서버 및 HMI 등)과 연계할 수 있는 기본 기능을 구성하여 V2X 통신 서비스 및 상태를 모니터링
    
2. 프로그램 활용 시 참고사항
- 본 프로그램 내 제공되는 참고문서의 경우, 일부 저작권이 포함되어 있으며 외부 활용 시 문서 내 기제된 담당자에게 허락이 필요할 수 있습니다.

3. 프로그램 코드
- 5G-NR-V2X.cpp : V2X 통신을 이용한 기본적인 차량 모니터링을 위한 샘플 코드로 실시간 차량 모니터링을 위한 용도의 프로그램
- 5GNR-GW-Hader : V2X 통신장치의 API를 연계하여 V2X 통신 정보를 송/수신을 위한 목적의 예제 코드 및 API 함수 구조체 정의
